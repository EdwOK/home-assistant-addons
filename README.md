# EdwOK's Home Assistant Add-ons

[![Add repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FEdwOK%2Fhome-assistant-addons)

Or add it manually: **Settings → Apps → App store → ⋮ → Repositories**, then
paste `https://github.com/EdwOK/home-assistant-addons`.

## Add-ons

| Add-on | Description |
|---|---|
| [Dahua P2P Tunnel](dh_p2p/DOCS.md) | Reach a Dahua VTO/camera over Dahua P2P (serial number), so the [Dahua integration](https://github.com/rroller/dahua) works when Home Assistant is not on the device's network. |
